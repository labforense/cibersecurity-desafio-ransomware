# Projeto de Ransomware Educacional com Python

Este projeto foi desenvolvido como parte de um desafio de Cibersegurança da DIO (Digital Innovation One). O objetivo é demonstrar, para fins estritamente educacionais, como funciona o processo de criptografia e descriptografia de arquivos utilizando o algoritmo AES.

## 🛡️ Tecnologias Utilizadas
* Python 3
* Biblioteca `pyaes` (Criptografia Simétrica)

## 🚀 Como Funciona
O projeto consiste em dois scripts principais:
1. **encrypter.py**: Localiza o arquivo alvo, aplica a criptografia AES e remove o arquivo original, substituindo-o por uma versão criptografada.
2. **decrypter.py**: Utiliza a chave simétrica correspondente para reverter o processo e restaurar o arquivo original.

## ⚠️ Aviso de Segurança
Este código foi criado para aprendizado sobre segurança cibernética. O uso dessas ferramentas em sistemas de terceiros sem autorização é ilegal e antiético.
