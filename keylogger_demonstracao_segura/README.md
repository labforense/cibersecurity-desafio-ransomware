# Keyloggers: conscientização defensiva

Um keylogger é uma ameaça capaz de registrar entradas do usuário para roubar senhas, mensagens e dados financeiros. Esta pasta não contém código de captura de teclado, monitoramento global, ocultação, persistência ou envio de informações.

## Indicadores a investigar

- Processos desconhecidos em execução ou configurados para iniciar com o sistema.
- Alertas do antivírus ou EDR relacionados a captura de entrada.
- Extensões de navegador e programas instalados sem autorização.
- Solicitações inesperadas de senha ou autenticação.

## Proteção

- Atualize o sistema e as ferramentas de segurança.
- Use autenticação multifator.
- Instale programas somente de fontes confiáveis.
- Revise permissões de aplicativos e extensões.
- Use senhas únicas, de preferência armazenadas em gerenciador de senhas.
- Reporte comportamentos suspeitos à equipe de TI ou segurança.

## Demonstração aceitável em aula

Uma demonstração segura pode solicitar conscientemente uma frase no terminal e explicar que dados inseridos em formulários e aplicativos podem ser sensíveis. Ela não deve registrar teclas fora do próprio programa, ficar invisível, iniciar com o sistema nem transmitir dados.
